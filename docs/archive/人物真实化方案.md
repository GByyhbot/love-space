# 人物形象真实化方案（参考素材 / 生成流程 / 提示词 / 合规）

> 目标：把现有 3D 人物形象做得更接近真实人类，消除"AI 感"与塑料感。
> 适用范围：`static/body.js`（人体模型页）+ 后续造型间。

---

## 0. 先定边界：三种用法，只有两种可行

| 方案 | 做法 | 对现有能力的影响 | 结论 |
|---|---|---|---|
| **A. 当风格/质感参考（推荐）** | 生成图只用于"看"：推导皮肤参数、光影、毛孔尺度、发丝走向、瑕疵分布；落地用程序化噪声 + 材质参数在 three.js 里复现 | **零影响**：不引入任何资产，保持离线、许可干净、包体不变 | ✅ 首推 |
| **B. 烘焙成贴图（可评估）** | 生成 albedo/roughness/normal 贴图打进包 | 包体 3.4MB → ~9MB；引入第三方资产、需许可审查；部署清单要加文件 | ⚠️ 需你拍板 |
| **C. 2D 预渲染图直接当角色** | 用生成图替换 3D | **毁掉** 360° 旋转、换装、后续动作 | ❌ 不做（与已放弃的"真人 AI 试衣"同类） |

**内容边界**：只生成头像/面部/皮肤/发丝/体态类素材。人体躯干部分以"运动着装的人像"或"古典雕塑/人体习作"方式取参考，不生成性化内容。

## 1. 参考素材获取（公开 + 允许商用）

### 1.1 推荐来源与许可要点（以官网最新条款为准，下载前必须复核）

| 来源 | 许可特点 | 适合取什么 |
|---|---|---|
| **Unsplash** | Unsplash License：免费商用、无需署名（署名仍推荐）；**不可**原样转售未修改副本 | 自然光人像、肤质特写、发丝逆光 |
| **Pexels** | Pexels License：免费商用、无需署名 | 同上，视频可做动态光影参考 |
| **Wikimedia Commons** | 按单文件标注（CC BY / CC BY-SA / PD），**必须逐张看署名要求** | 古典雕塑、人体习作（无肖像权顾虑） |
| **模特公开作品集 / 图库样图** | 需逐站看 Terms，多数仅"编辑用途" | 姿态、用光；**不要**拿来当纹理 |
| **博物馆开放扫描**（如 Rijksmuseum、Smithsonian Open Access） | 多为 CC0 / Public Domain | 雕塑解剖、衣褶、体态（**零肖像权风险，强烈推荐**） |

### 1.2 筛选标准（照此挑图，质量才稳定）

- 光线：**单一主光 + 环境反弹**，能看清皮肤明暗过渡；避免环形灯/美颜灯（那正是塑料感来源）
- 皮肤：能看到毛孔、细绒毛、油光分区（T 区/肩/鼻），不磨皮
- 头发：有碎发/飞丝，边缘不是整齐色块
- 姿态：重心偏一侧（contrapposto），两肩不等高
- 焦段：人像 85–135mm；全身 35–50mm（全身别用长焦，会失真）
- 分辨率：短边 ≥ 1500px（肤质参考建议 ≥ 3000px）

### 1.3 实操（本地归档 + 记录许可）

```bash
# 目录结构建议（.workbuddy/ 已被 git 忽略，参考图不会进仓库）
mkdir -p .workbuddy/ref/{female,male}/{face,skin,hair,pose,light}

# Pexels API（需申请 key）
curl -s "https://api.pexels.com/v1/search?query=portrait%20natural%20light%20skin&per_page=30" \
  -H "Authorization: $PEXELS_API_KEY" | jq '.photos[].src.large2x'

# Unsplash API（需申请 key）
curl -s "https://api.unsplash.com/search/photos?query=skin%20texture%20macro&per_page=30" \
  -H "Authorization: Client-ID $UNSPLASH_ACCESS_KEY" | jq '.results[].urls.full'
```

**每张图必须记一条元数据**（`refs.csv`）：`文件名,来源URL,作者,许可,下载日期,用途`。
理由：日后任何商用/分发审查，都要能逐张追溯到许可来源。

### 1.4 明确避免

- 名人/明星照片、看起来像具体真人的肖像（人格权风险）
- 未标许可的"免费图站"、带水印图
- 医学院/健身类未授权真人裸图
- 用真人照片直接当 3D 贴图（肖像权 + 可识别性双重风险）

## 2. 生成流程（基于参考图产出更逼真形象）

### 2.1 模型选型对比

| 方案 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| **本地 SDXL**（ComfyUI） | 数据不出机、可控（LoRA/ControlNet）、可批量 | 需 8GB+ 显存；写实人像底模要挑 | 本项目首推（数据不出 NAS 原则） |
| **本地 Flux.1[dev]** | 皮肤质感与手部更稳、解剖错误更少 | 显存要求更高（12GB+） | 有卡就用它 |
| **云端 API** | 无需显卡、出图快 | **提示词出网**；按张计费；条款各异 | 只在不涉及任何用户数据时使用 |

> 本项目此前的原则"用户数据只留 NAS"针对的是**用户上传的照片/隐私数据**；生成提示词（不含用户数据）走云端不违背该原则，但仍建议优先本地。

### 2.2 提示词结构公式

```
[主体与年龄] + [皮肤质感与瑕疵] + [发丝] + [姿态与微表情] + [光线] + [镜头焦段与光圈] + [环境与背景] + [后期/胶片感]
```

### 2.3 参数范围

| 项 | SDXL | Flux.1[dev] |
|---|---|---|
| 分辨率 | 肖像 1024×1536；全身 1216×832 | 1024×1024（再放大） |
| steps | 32–40 | 24–32 |
| CFG / guidance | 5–7 | 3.0–4.5 |
| sampler | DPM++ 2M Karras / Euler a | euler / beta |
| Hires 修复 | ×1.5，denoise 0.40–0.55 | 同左 |
| img2img（用参考图起步） | denoise 0.35–0.50 | 0.35–0.45 |
| seed | 固定便于复现；真实化请跑 4–8 个 seed 挑最自然的 | 同左 |

### 2.6 体态 / 质感特写模板（给 3D 材质取参数用）

```text
# 皮肤（做 roughness / 毛孔尺度参考）
macro close-up of human skin on the upper back, visible pores, fine hair, slight reddening,
natural oil sheen variation, raking sunlight, 100mm macro, f/8, sharp, no retouching

# 体态（避免性化：着运动装 / 或取古典雕塑）
full body figure study of an athletic {woman}, standing contrapposto with weight on one leg,
one shoulder slightly lower, wearing plain {black} bodysuit and shorts, soft studio light with
large softbox, subtle shadow under the chin and arms, 50mm, f/4, sharp throughout, natural
fabric wrinkles, neutral gray background

# 发丝（做发片/边缘参考）
backlit hair strands, individual hairs glowing at the edges, flyaway hairs, shallow depth of
field, 135mm, f/1.8, natural light, no retouching
```

### 2.7 去"AI 感"的 12 条硬规则

1. 双眼大小差 2–4%、眉高差 1–3mm、嘴角不完全对称
2. 两肩不等高（差 0.5–1cm 量级）、重心偏一侧
3. 皮肤必须有**毛孔 + 绒毛 + 油光分区**（T 区亮、颊部哑光）
4. 保留瑕疵：痣、雀斑、轻微泛红、一颗小痘印
5. 头发必须有碎发/飞丝，边缘不要整齐
6. 微表情：眼神略偏、嘴角一侧略高，不要"标准微笑"
7. 焦段与景深：人像 85–135mm + f/1.8–2.8；全身 35–50mm + f/4–5.6
8. 单一主光 + 反弹光，禁止环形灯/双打光（塑料感元凶）
9. 环境色溢出：背景色轻微染到皮肤边缘
10. 手部：指甲形状不完全一致、指节有皮纹
11. 衣褶/布料有真实压痕与松弛
12. **绝不磨皮、绝不完美对称构图**

## 3. 后期处理（2D 出图 → 3D 等价做法）

| 项目 | 2D（PS/LR） | 3D 等价（three.js） |
|---|---|---|
| 色调 | S 曲线；阴影 +8~12，高光 −10；橙色饱和 −5、亮度 +3 | `toneMappingExposure` 1.05 → 0.98；ACES 保留 |
| 颗粒 | 强度 22–32，颗粒 1.0–1.6，单色 | 全屏 pass：`grain ≈ 0.035`（随时间抖动） |
| 锐度 | USM 65–85 / 半径 1.1–1.4 / 阈值 3–5 | 只靠高分辨率渲染，避免 shader 内过度锐化 |
| 分离色调 | 高光 +暖 3%、阴影 +冷 2% | rim light 暖、fill light 冷（现有已是） |
| 暗角 | 强度 ~25% | vignette 0.20–0.28 |
| 色散 | 边缘 0.1–0.2% | CA 0.0015（仅边缘） |

## 4. 授权与合规（必读）

1. **肖像权/人格权**：只用**合成人脸**；禁止用真实人物姓名/肖像微调；reference 图仅作风格参考，**不得**投影到可识别的真人身上。
2. **商用范围**：逐张核对来源许可（Unsplash/Pexels 可商用但不可原样转售；CC BY 需署名；CC BY-SA 有传染性，慎用）。
3. **AI 标注**：产品内若展示生成图，应标注"AI 生成"；平台（应用商店/小程序）可能有额外要求。
4. **平台条款**：云端生成服务对内容有各自条款，商用前确认是否允许商业用途。
5. **本项目额外约束**：不上传用户照片到任何云端；参考图与生成图只落在 NAS/本地。
6. **可追溯**：保留 `refs.csv`（来源/作者/许可/日期），随时能过审。

## 5. 工程落地：3D 侧消除塑料感（零资产路线 A）

这才是本项目的正解——**不引入任何位图**，在 `static/body.js` 里把质感做出来：

| 手段 | 具体做法 | 代价 |
|---|---|---|
| 材质升级 | `MeshStandardMaterial` → `MeshPhysicalMaterial`；roughness 0.62 基础 + 程序噪声 ±0.12；clearcoat 0.06–0.10（T 区/肩/胸）；sheen 0.15（头发） | 几乎免费 |
| 假 SSS | `onBeforeCompile` 注入 wrap diffuse（wrap≈0.35）+ 透光项（耳/鼻 0.25） | +1 次 shader 编译 |
| 程序化毛孔 | 运行时用 canvas 生成 512² 噪声 normal/roughness（非资产文件） | 一次性 ~10ms |
| 光照 | key 2.0→1.85、rim 0.95→0.80、加一盏 0.35 地面反弹；程序化渐变天空 env 给反射 | 免费 |
| 不对称 | 眼位 ±0.6°、眉高差 0.004、肩高差 0.006、站姿重心偏移 0.010、加 1–2 颗痣 | 免费 |
| 后处理 | grain 0.035 + vignette 0.25 + CA 0.0015（自写 ~40 行全屏 pass，不加新依赖） | +0.3–0.6ms/帧 |

### 风险清单

| 风险 | 影响 | 缓解 |
|---|---|---|
| 引入位图资产 | APK 3.4MB→~9MB、许可审查、部署清单要加 | 优先路线 A；若走 B，单张 ≤2048² 并 BC 压缩 |
| 云端生成 | 提示词出网（非用户数据） | 优先本地 ComfyUI/Flux |
| 肖像权 | 可识别真人风险 | 只用合成脸 |
| 2D 替代 3D | 毁掉旋转/换装/动作 | 明确不做 |
| 性化内容 | 合规风险 | 只生成头像/着装体态/雕塑参考 |
