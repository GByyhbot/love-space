数据源：她（`20010625`）2026-11-28 唯一移动段，77 原始点 → 高德 `v4/grasproad/driving` 纠偏后 214 点。
检测方式：纠偏后点列里找「出去再回到 30 m 内」的子段，取最长者。

```

距主弦最大偏离 = 272.3 m
位置 = 第 35..39 个纠偏点之间（图上西大墩岭附近那根 T 形支线）
```

**结论：机主口述的「折回不到 100 米」阈值抓不住这段**（实际 561 m / 偏离 272 m）。
建议判据（二选一，请规格定稿时明确）：

- **A. 放宽长度阈值**：`折回路径长度 ≤ 700 m 且 回归点间距 ≤ 30 m` → 剔除；
- **B. 改用偏离判据（更稳）**：`偏离主弦 > 50 m 且 2 点内回归到 ≤30 m` → 剔除此前的悬空段。

> 提醒：阈值放宽会增加误杀真实折返（如掉头、进小区再出来）。B 判据不受长度影响，但要求先有"主弦"概念（相邻保留点连线），实现上更适合放在展示层。
